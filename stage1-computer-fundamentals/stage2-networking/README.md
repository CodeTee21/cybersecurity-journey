# Stage 2: Networking Fundamentals

## Introduction
Networking allows computers and other devices to communicate and share information. Understanding how networks work is important in cybersecurity because it helps us understand how data moves between devices.

## 1. What Is a Network?
A network is a group of connected devices that communicate and share resources, such as files, printers, and internet access.

## 2. LAN and WAN
Networks can cover different geographical areas.

- **LAN (Local Area Network):** Connects devices within a limited area, such as a home, school, or office.
- **WAN (Wide Area Network):** Connects devices across larger geographical areas, such as different cities or countries.

## 3. IP Address
An IP address is a numerical address used to identify a device on a network and help data reach the correct destination.

## 4. MAC Address
A MAC address identifies a network interface. It is commonly used to identify devices communicating over a local network.

## 5. Router
A router connects different networks and forwards data between them. For example, a home router connects devices in your home network to the internet.

## 6. Switch
A switch connects devices within a local network and forwards data to the appropriate device.

## 7. DNS
DNS stands for Domain Name System. It translates domain names, such as `google.com`, into IP addresses that computers use to locate servers.

## 8. Ports
Ports help a computer direct network traffic to the correct application or service. For example, HTTPS commonly uses port 443.

## 9. TCP and UDP
TCP and UDP are communication protocols used to send data across networks.

- **TCP:** Provides reliable delivery and checks that data arrives correctly.
- **UDP:** Sends data with less delivery checking, which can make it useful for applications that prioritize speed.

## 10. HTTP and HTTPS
HTTP is a protocol used to transfer information between web browsers and web servers. HTTPS adds encryption to protect information while it travels between them.

## Conclusion
Through this stage, I learned the basic concepts of networking and how devices communicate. This knowledge provides a foundation for understanding network security and identifying potential security risks.
