# Stage 3: Linux Fundamentals

## Introduction
I learned the basics of Linux and practised using the Ubuntu terminal as part of my cybersecurity journey.

## Commands I Practised

- `pwd` — displays the current working directory.
- `ls` — lists files and directories.
- `cd` — changes directories.
- `mkdir` — creates directories.
- `touch` — creates empty files.
- `cat` — displays file contents.
- `echo` — displays text or writes text into a file.
- `cp` — copies files.
- `mv` — moves or renames files.
- `rm` — removes files.
- `rmdir` — removes empty directories.
- `find` — searches for files and directories.
- `grep` — searches for text inside files.
- `chmod` — changes file permissions.
- `sudo` — runs commands with administrator privileges when authorized.
- `whoami` — displays the current username.

## File Permissions
I learned about read (`r`), write (`w`), and execute (`x`) permissions.

I practised using `ls -l` to view file permissions and `chmod` to change them.
