## Overview
This stage focused on learning Python fundamentals and applying them to basic cybersecurity tasks.

## Topics Learned
- Variables and user input
- Data types and type conversion
- Conditional statements (`if`, `elif`, `else`)
- Loops (`for` and `while`)
- Functions
- Lists and dictionaries
- Exception handling (`try` and `except`)
- Python modules and imports
- IP address validation using `ipaddress`
- DNS lookup using `socket`

## Project: Cybersecurity Investigation Tool

### Description
A beginner-friendly Python project that performs DNS lookups to retrieve the IPv4 addresses associated with domain names.

### Modules Used
- `socket` – performs DNS lookups.
- `subprocess` – clears the Linux terminal.

### Features
- Accepts domain names from users.
- Removes unnecessary spaces and converts input to lowercase.
- Retrieves IPv4 addresses.
- Handles unsuccessful DNS lookups.
- Stores successful lookups in a list of dictionaries.
- Displays investigation history.

### What I Learned
I learned how to combine Python fundamentals and built-in modules to create a simple cybersecurity-related tool.
