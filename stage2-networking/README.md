# Stage 2: Networking Fundamentals

## Introduction
Networking allows computers and other devices to communicate and share information. Understanding networking is important in cybersecurity because it helps us understand how data moves between devices.

## 1. What Is a Network?
A network is a group of connected devices that communicate and share resources, such as files and internet access.

## 2. LAN and WAN
- **LAN (Local Area Network):** Connects devices within a small area, such as a home, school, or office.
- **WAN (Wide Area Network):** Connects devices across large geographical areas.

## 3. IP Address
An IP address identifies a device on a network and helps data reach the correct destination.

## 4. MAC Address
A MAC address identifies a network interface on a device.

## 5. Router
A router connects different networks and forwards data between them.

## 6. Switch
A switch connects devices within a local network and forwards data to the appropriate device.

## 7. DNS
DNS stands for Domain Name System. It translates domain names, such as `google.com`, into IP addresses.

## 8. Ports
Ports help computers direct network traffic to the correct application or service. HTTPS commonly uses port 443.

## 9. TCP and UDP
- **TCP:** Provides reliable data delivery.
- **UDP:** Sends data with less delivery checking and is useful when speed is important.

## 10. HTTP and HTTPS
HTTP transfers information between web browsers and web servers. HTTPS adds encryption to protect information during transfer.

## Conclusion
I learned the basic concepts of networking and how devices communicate. This knowledge provides a foundation for understanding network security.
